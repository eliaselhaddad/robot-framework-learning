# Robot Framework Learning Project

This repository is a learning project for Robot Framework and Python test automation.

## Goals

- Learn Robot Framework step by step.
- Understand test cases, keywords, variables, setup/teardown, loops, resources, and Python libraries.
- Progress toward practical QA and embedded-system test automation.
- Keep each lesson in a separate numbered file under `lessons/`.

## Project Structure

- `lessons/` - Learning exercises and Robot Framework test suites.
- `resources/` - Reusable Robot Framework resource files.
- `libraries/` - Custom Python libraries used by Robot Framework.

## Coding Guidelines

- Keep examples simple and beginner-friendly.
- Do not rewrite completed lessons unless specifically requested.
- Add documentation to Robot Framework suites, tests, and keywords when it provides useful context beyond an obvious name or implementation.
- Prefer readable keyword names.
- Explain changes before making major structural changes.
- Python code should remain simple and readable.
- Avoid adding unnecessary dependencies.

## Learning Rule

Do not solve learning exercises automatically unless explicitly asked.

When helping with an exercise:

1. Explain the concept.
2. Give hints first.
3. Let me attempt the implementation.
4. Review my solution afterward.

## Session Workflow

At the start of every Codex session:

- Read `PROGRESS.md`.
- Inspect the current project state before making changes.
- Continue from the current lesson or task.
- If `PROGRESS.md` appears outdated, inspect the current project files and git state, reconstruct the latest progress, and update `PROGRESS.md` before continuing.

When I say `handoff`:

- Update `PROGRESS.md` for the next session.
- Record what was completed.
- Record unfinished work.
- Record the next recommended step.
- Give me a short summary.

## Documentation Maintenance

- Keep `README.md` aligned with meaningful project progress.
- Update `README.md` when:
  - a new lesson is completed
  - a new project folder or major file type is introduced
  - the project goals or next steps change
- Do not update `README.md` for trivial edits or small fixes.
